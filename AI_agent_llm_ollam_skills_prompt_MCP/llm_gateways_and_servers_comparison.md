## 📌 Summary Categories

* **Proxy / Gateway / Aggregators:** Tools like *LiteLLM, OmniRoute, Portkey Gateway, Bifrost, One-API, New-API* function as central hubs to manage API keys, fallback rules, and request limits.
* **Local Inference Engines:** Tools like *Ollama, LocalAI, LlamaEdge, FastChat, TGI* allow completely offline, hardware-based execution without external cloud dependencies.
* **Smart Routers:** Tools like *RouteLLM, LLMRouter, Glm-router* evaluate query difficulty or cost parameters before routing traffic to appropriate models.
* **Enterprise & Security Gateways:** Systems like *Envoy AI Gateway, Kong, APISIX, BricksLLM, OpenZiti* provide zero-trust security, OAuth2, and Kubernetes-native capabilities.
